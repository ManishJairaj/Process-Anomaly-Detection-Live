🖥️ Detector Controls & Launch Instructions
Privilege Separation Protected

Because kernel eBPF tracepoints require CAP_BPF or administrator privileges, the web server runs safely unprivileged and connects directly to the detector's incremental log output. To start or control monitoring, execute the commands below in your host terminal:

# Option 1: Launch Live eBPF Kernel Collector (Requires sudo in Ubuntu terminal)
sudo ./ebpf/syscall-detector-live -m baseline_model.dat -o syscall_dataset.csv -q
# Option 2: Run Safe Unprivileged Ground-Truth Workload Suite (No sudo required)
./tools/workload_runner.sh --model baseline_model.dat --output gt_eval_dataset.csv
# Option 3: Stop Active Detector Instance
sudo pkill -SIGINT -f syscall-detector-live
